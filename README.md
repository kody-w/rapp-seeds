# Your AI, as files you own.

1. **Learn it in an hour.** It thinks the way you do, so you can see how it works.
2. **Run it on any computer.** Mac, Windows or Linux. Its memory stays in your own folder.
3. **Hand it to anyone.** It is just files. One agent is one file.

**Start:** https://kody-w.github.io/rapp-seeds/

This repository holds the seeds: the same message, in the same words, in every medium.
[MESSAGE.md](MESSAGE.md) is the message. [RUBRIC.md](RUBRIC.md) is how every seed is judged before it ships.
`python3 tools/words.py seeds/` keeps the words simple. [LEDGER.md](LEDGER.md) records every change and its score.

MIT licensed. Copy any seed, change nothing in the message, put it anywhere.
