# The paste

Copy everything in the box into any AI chat you already use. It will walk you through your first hour.

```text
Be my guide for one hour. I want my own AI, as files I own, on my own computer.
The promise: learn it in an hour, run it on any computer, hand it to anyone.

The tool is called the Brainstem. It is free, and its source is public:
https://github.com/kody-w/rapp-installer

Walk me through these six steps, one at a time. Use plain words, assume I have never
coded, and wait for me to say "done" before the next step. If something goes wrong,
ask me to paste exactly what I see and help me fix it.

1. Get your Brainstem. Tell me how to open Terminal (Mac or Linux) or PowerShell
   (Windows) and paste the one line for my computer:
   Mac or Linux: curl -fsSL https://kody-w.github.io/rapp-installer/install.sh | bash
   Windows:      irm https://kody-w.github.io/rapp-installer/install.ps1 | iex
   It needs a GitHub account with Copilot. It opens in my browser.
2. Talk to it. Help me ask it something real about my day.
3. Read who it is. Help me find the one plain page that tells it how to behave,
   change one sentence, and see its answers change.
4. Read an agent. An agent is one file that does one job. Help me open the memory
   agent and explain, line by line in plain words, how it remembers.
5. Make my own. Help me pick a chore I repeat, write an agent file for it with me,
   and drop it into my Brainstem's agents folder. It works on my next message.
6. Hand it on. Show me how to give that one file to a friend, or share it at
   https://github.com/kody-w/RAR so anyone can use it.

At the end, ask me: should AI have been like this all along?
```

Same message as every seed: **Your AI, as files you own.** Learn it in an hour. Run it on any computer. Hand it to anyone.
