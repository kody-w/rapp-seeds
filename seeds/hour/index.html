Your AI, as files you own.

  • Learn it in an hour (being tested). It thinks the way you do, so you can see how it works.
  • Run it on any computer. Mac, Windows or Linux (being tested). Its memory stays in your own folder.
  • Hand it to anyone. It is just files. One agent is one file.

This installs your Brainstem: the small program on your computer that runs your AI. On a Mac, press Command and Space, type Terminal, press Enter, then paste this line and press Enter.

curl -fsSL https://kody-w.github.io/rapp-installer/install.sh | bash

On Windows, press the Windows key, type PowerShell, press Enter, then paste this line and press Enter.

irm https://kody-w.github.io/rapp-installer/install.ps1 | iex

Your first hour

Six steps, about ten minutes each. No coding.

  1. Get your Brainstem.Paste the line above. Sign in once with a GitHub account that has Copilot. It opens in your browser and runs while that Terminal window is open. Paste the same line any time to bring it back, memory and all.
  2. Talk to it.Tell it one thing to remember about you, like your favorite coffee. If it does not save it, say: remember that, it matters to me. Tomorrow, ask it what it remembers. Your Brainstem, its agents and its memory stay on your computer. The model that writes the answers is Copilot, over the internet.
  3. See what it can do.Click the circled plus ⊕ at the top right of your Brainstem (it says Manage installed agents when you point at it). Each one listed is an agent: one file that does one job. Think of each one as a neuron in a brain: when your message needs its job, it fires and does it.
  4. Read an agent.Click Export next to ManageMemory. Your browser saves a small file, usually in Downloads. Drag it into a chat with any AI and ask: Explain this in plain words. It is a short program for one job: saving what you ask it to remember.
  5. Make your own.In the same chat, ask for a new agent just like it, for a chore you repeat, as a file you can download. Drag that file onto your Brainstem window and click OK when it asks. Your Brainstem just grew a new neuron. From your next message on, it fires whenever your message needs its job. If it says the agent did not load, paste that message into the chat and ask for a fix.
  6. Hand it on.Export your new agent and send the file to a friend. They drag it onto their Brainstem and it works the same way (being tested). Or share it in the registry.

Tomorrow it is still there, on your computer, remembering (being tested this week). That is the moment people say: AI should have been like this all along.

Details for builders

Go deeper: your Brainstem lives in one folder. On a Mac, paste open ~/.brainstem/src/rapp_brainstem into Terminal. On Windows, paste explorer $HOME\.brainstem\src\rapp_brainstem into PowerShell. The page soul.md tells it how to behave: change a sentence and its answers change. Agents live in agents/.

The Brainstem is one small program, and its source is public. It uses your GitHub Copilot sign-in for the model. Your agents, its page of instructions and its memory are plain files in one folder on your computer. When Copilot writes an answer, the Brainstem sends it your message and the memories it needs.

RAPP is the open format underneath, free for anyone, MIT licensed. Anyone can build a Brainstem in any language and check it against the original with the public test suite of 25 checks. The suite runs automatically on every change, and it checks the memory promise too: save one thing, restart, and it is still there.
