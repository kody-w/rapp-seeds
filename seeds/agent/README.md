# The FirstHour agent

Your first hour, as one agent. [Download first_hour_agent.py](https://kody-w.github.io/rapp-seeds/seeds/agent/first_hour_agent.py),
drag it onto your Brainstem window, and click OK. Then say: *teach me my first hour.*

It walks you through the same six steps as the [hour page](https://kody-w.github.io/rapp-seeds/), one at a time.
Open the file and read it: it is one file that does one job, like every agent.

Your AI, as files you own. Learn it in an hour. Run it on any computer. Hand it to anyone.
