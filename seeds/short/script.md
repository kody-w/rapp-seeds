# The 60-second short

Vertical, 9:16, about 60 seconds. Real screen recordings only. Same message as every seed.

| Time | On screen | Voice |
|---|---|---|
| 0-4 | Big text: **Your AI, as files you own.** | "What if your AI was just files you own?" |
| 4-12 | A Terminal window. One line is pasted. A browser opens on the Brainstem. | "One line, on a Mac, Windows or Linux computer. This is a Brainstem." |
| 12-22 | Typing: *Remember that my favorite coffee is a flat white.* | "Tell it something." |
| 22-32 | The Terminal window closes. The line is pasted again. Typing: *What do you remember about me?* The answer names the flat white. | "Close it. Open it again. It remembers, because the memory is a file on your computer." |
| 32-42 | The agents panel opens. Export is clicked on one agent. A short file is shown. | "Everything it can do is an agent. One file, one job. You can read it." |
| 42-52 | A file is dragged onto a second person's Brainstem. It answers using that agent. | "Hand that file to a friend, and it works for them too." |
| 52-60 | Big text: **Learn it in an hour. Run it on any computer. Hand it to anyone.** Then the page address. | "Learn it in an hour. AI should have been like this all along." |

On-screen address at the end: kody-w.github.io/rapp-seeds

Rules for whoever films it: real screens, no mockups; the answer that names the coffee must be the real answer;
blur any private names in the recording; nothing on screen that is not in the steps above.
